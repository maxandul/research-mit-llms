# Quellnotizen

Eine Notiz pro Quelle, in eigenen Worten. Aufbau jeder Notiz:
bibliografische Angaben, Evidenzstufe, Verifikationsvermerk, Kernaussagen,
Einordnung, Relevanz für diese Website, Querverweise.

Die Notizen entstehen sprintweise pro Thema, siehe
[Arbeitsweise](../index.md#arbeitsweise).
