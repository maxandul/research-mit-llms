# Weitere Tools im Überblick

Diese Dienste sind für Forschende relevant, haben aber bewusst keine eigene
Anleitung — der Kurzüberblick reicht zum Einordnen. Details auf den
verlinkten offiziellen Seiten.

- **Research Rabbit** — Literatur-Discovery über Zitationsnetze, kostenlos.
  Ähnlich [Connected Papers](finden/connected-papers.md).
  <https://www.researchrabbit.ai>
- **scite.ai** — zeigt, *wie* eine Arbeit zitiert wird (bestätigend vs.
  widersprechend). Kostenpflichtig. <https://scite.ai>
- **Consensus** — zieht direkte Antworten auf Forschungsfragen aus Papers.
  Überschneidet sich mit [Elicit](finden/elicit.md).
  <https://consensus.app>
- **SciSpace** — Chat mit PDFs und Literaturerklärungen.
  <https://scispace.com>
