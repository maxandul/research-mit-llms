# Rohdaten (nur lokal)

Hier liegen die Volltexte (PDFs) der Quellen für das
Forschungsstand-Wiki, siehe `docs/wiki/` und die Spielregeln in
`CLAUDE.md`.

**Alles in diesem Ordner ausser dieser README ist per `.gitignore`
ausgeschlossen und wird nie gepusht** — die Volltexte sind
urheberrechtlich geschützt und gehören nicht in ein öffentliches
Repository.

Ablage-Konvention: ein Dateiname pro Quelle, passend zum Slug der
Quellnotiz, z.B. `schilke-reimann-2025-transparenz-dilemma.pdf` zu
`docs/wiki/quellen/schilke-reimann-2025-transparenz-dilemma.md`.
